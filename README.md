# *chimera-portfolio*

A lightweight, static, single-page website template designed to be used with the Neocities hosting service. 

Useful for anyone who wants a fully customizable framework to build a portfolio off of. As long as you have some very basic knowledge of HTML / CSS and you're willing to go to Google with extra questions, this template should be right up your alley.

### How to navigate these files:

This project is sorted into four main folders within the `./public` directory: `fonts`, `fragments`, `images`, and `style`. Alongside these is `index.html`, which provides the backbone of the single-page architecture by using simple Javascript to string together HTML elements from the `fragments` folder.

Complex files (particularly the different CSS stylesheets in `style`) all contain explanatory comments where relevant, in order to make customization as easy and comprehensible as possible.

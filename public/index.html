what is this site about?

Looking for somewhere to set up an online portfolio? Annoyed with the mainstream, personality- scrubbed, non-customizable sites that seemed like the only option? Then you've come to the right spot.

chimera-portfolio is your new digital business card: a simple, static, 100% free website template that YOU can download, customize, and make your own, even if you're completely new to web design.

wait, really?

It's true! I've done the heavy lifting of setting up the basic framework so you can stylize it however you see fit. And, the more you want to get out of this template, the more you'll be able to do. Even just a little bit of extra knowledge about HTML and CSS will get you a long way!

With this template, you can express your vision to your heart's content, and to whatever extent you please.

but I know nothing at all about websites!

That's no problem either. This site is designed to be as easy to modify as possible, and though you may find that there's a bit of a learning curve to web design, you can always check out the setup guide page (or just go to Google!) if you start feeling lost.

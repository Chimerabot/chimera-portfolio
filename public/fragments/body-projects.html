These are some old graphic design projects of mine. Cool, right?

As you can tell, these minimal images are just a placeholder, but this page can be useful for a lot more. I'll leave the specific formatting to you, but a page like this one is essential. Links and images that show or demonstrate work you've done are the core of any portfolio.

Try changing the size of the webpage to watch the images flexibly move around! The framework I've set up here, and across the website, is optimized to be as flexible as possible so that it can be rendered at any standard resolution, whether on a computer, a phone or a tablet. The images also dynamically resize alongside their surroundings.
